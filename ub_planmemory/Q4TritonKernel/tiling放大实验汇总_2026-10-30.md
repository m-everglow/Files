# Q4 Triton Kernel 固定 tiling 对照结果

每个 case 只保留一个目标 autotune 配置，用相同 case、相同 tiling 和同一物理卡分别运行 stable、current。成功项已核对实际选型。

## 总结

- 143 个 case，共 366 组固定 tiling 配对（732 次原始运行）。
- 两版均通过 84 组；两版均失败 282 组；current 独有通过 0 组；stable 独有通过 0 组。
- 初测有 11 组 stable 通过、current 运行时失败；这 11 组在原卡、原配置下重跑后均通过，按复跑结果计。
- 因此本批目标 tiling 没有出现 current 比 stable 能运行更大的例子。
- 本批有 103 个纯 VECTOR case、40 个 CUBE/VECTOR 混合 case；没有纯 CUBE case。混合 kernel 实际暴露的 tiling 轴是 BLOCK_H/BLOCK_N。
