# PV 改为 L1 双槽、UB 单槽

## 容量分析

保留 QK 的 UB 双槽。C2 输出先从 L0C 写入 PV 的 L1 双槽，再按奇偶选槽，搬到每个 AIV 的一个 UB buffer，供 V2 使用。

L1 中的 PV 是完整 CUBE tile：128×128×f32，每槽 64 KiB，双槽 128 KiB。进入每个 AIV 的半块是 64×128×f32，UB 单槽 32 KiB。

| L1 buffer | 大小 |
|---|---:|
| Q | 32 KiB |
| K | 64 KiB |
| V | 64 KiB |
| P 双槽 | 128 KiB |
| PV 双槽 | 128 KiB |
| 合计 | **416 KiB / 512 KiB** |

PlanMemory 实际输出与上述总量一致：K/V 独立，未发生复用。L1 地址占到 416 KiB，剩余 96 KiB。

| 每个 AIV 的 UB buffer | 大小 |
|---|---:|
| QK 双槽 | 128 KiB |
| PV 单槽 | 32 KiB |
| acc | 32 KiB |
| mask | 16 KiB |
| P 输出（含对齐） | 32.5 KiB |
| 行统计等小 buffer | 3 KiB |
| 实际规划占用 | **243.5 KiB / 248 KiB** |

UB 剩余 4.5 KiB。这里统计的是规划输出的物理地址占用，不是把复用的 SSA 重复相加。

## 修改与同步

- C1→V1 的 QK 路径、UB 双槽及其信号保持原样。
- C2 的两个 PV UB buffer 改为两个私有 L1 buffer，保留奇偶选槽。
- 增加 C2 内的 L1→UB 双 AIV 传输，每个 AIV 只用一个 PV UB。
- AIV 初始发“PV UB 空闲”，C2 搬运前等待；搬运后通知 V2 数据就绪，V2 使用完再归还。
- L1 槽的读写保护由 GSS 根据新 IR 重新生成。
- 原 ssbuffer 调度条件和计数容量没有修改，本次先验证 C2 内完成搬运的版本。
