# FP32输出复用PV的UB

128×128：FP32输出使用独立32 KiB UB，起始地址208384。不与P和acc复用。

128×256 PV L1版：现有UB占用243.5 KiB，另加32 KiB会超过248 KiB。因此此次在PlanMemory输出IR中，只将FP32输出%120从P地址16384改到PV地址181504，不使用acc，不增加UB总量。AIC/AIV仍为N+2。

使用顺序：当前任务V2读完PV，再由最终VF写FP32输出并store；下一任务先执行C1/V1，再执行C2并写PV。下一任务P的UB→L1 copy与上一任务GM store同属MTE3且顺序在后；C2等P就绪后才能产生新PV，保护此处跨任务复用。

同步IR：循环前的MTE3→V等待已消失；P的event0在kernel入口初始化、出口回收，跨任务延续。FP32 store使用event1保护最终VF。仅从IR确认等待范围已改变，尚未采新流水确认实际重叠程度。

验证原case：test_swa_function_fwd_perf[False-4-1023-M_BF16_1024]。只保留原case精度检查和kernel计时。
