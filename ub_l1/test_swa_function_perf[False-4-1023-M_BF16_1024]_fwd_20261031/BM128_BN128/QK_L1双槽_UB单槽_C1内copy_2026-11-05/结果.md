# 128×128：AIC multibuffer，QK经L1双槽/C1内copy

**编译通过，原case精度通过；本次kernel性能明显慢于原AIC multibuffer版。**

## 修改与IR确认

- 保持算子当前调用的multibuffer=True、limit_auto_multi_buffer_buffer="only-cube"。BM=BN=128及其他参数沿用原脚本，未额外固定num_warps或num_stages。
- QK由UB双槽改为L1双槽。两个L1槽各64 KiB，AIV工作UB为32 KiB单槽。
- C1直接执行matmul→FIX到所选L1槽→L1到UB copy→通知V1；没有新增ssbuffer调度块。
- QK归还/就绪信号改为V与MTE1之间的单槽握手。P、PV路径保持原样。
- 原调度块编号、for循环上界和N+2保持不变。没有改VF计算。
- QK两个私有L1槽与UB工作槽显式标为单槽，避免全局自动multibuffer再次扩成四槽/UB双槽。Q/K/V加载原有的AIC自动双槽仍保留。
