# 128×128：UB与L1总体使用情况

对应原128×128基线，FP32输出开启；仿真与硬件执行的二进制SHA256一致：a7a1af1400b18f26a3fe7d0023a769bb9e8f32b31e6e73bd7ad3e9da4d999d6c。

## 总体

| 内存 | 容量 | PlanMemory规划后地址占用 | 剩余 | 占用率 |
|---|---:|---:|---:|---:|
| UB，每个AIV | 248 KiB | **243.5 KiB** | 4.5 KiB | 98.19% |
| L1，每个AIC | 512 KiB | **160 KiB** | 352 KiB | 31.25% |

这里统计所有已分配地址的范围，不是某一时刻同时存活的峰值。AIC与两个AIV中的跨核buffer镜像不重复计数。UB按每个AIV计算，L1是两个AIV与AIC所在计算组共同访问的AIC侧空间。

原before PlanMemory IR逐alloc相加：UB **276.25 KiB**，L1 **160 KiB**，不做复用。与规划后地址占用是两种统计口径。

| 用途 | 大小 |
|---|---:|
| QK双槽 | 32 KiB × 2 = 64 KiB |
| PV双槽 | 32 KiB × 2 = 64 KiB |
| GM mask加载双槽 | 8 KiB × 2 = 16 KiB |
| P，VF1的NZ输出，含padding | 16.25 KiB |
| acc | 32 KiB |
| 最终LSE输出 | 0.25 KiB |
| 最终BF16输出 | 16 KiB |
| 最终FP32输出 | 32 KiB |
| 初始化源、两组三槽状态及VF小向量 | 3 KiB |
| **合计** | **243.5 KiB** |

这些表项已经按复用后的物理地址去重。VF0结果与VF1部分小输出同址，acc初值和更新值同址；不重复相加。

### 输出地址独立

以下SSA属于实际编译后的module.hivm.opt.mlir中的AIV入口，区间为[起点,终点)，单位B。

| 用途 | SSA | 地址范围 | 大小 |
|---|---|---|---:|
| P | %226 | [142080,158720) | 16.25 KiB |
| acc | %160 / %265 | [158976,191744) | 32 KiB |
| LSE输出 | %349 | [191744,192000) | 0.25 KiB |
| BF16输出 | %350 | [192000,208384) | 16 KiB |
| FP32输出 | %351 | [208384,241152) | 32 KiB |
| mask槽0 | %51 | [133120,141312) | 8 KiB |
| mask槽1 | %53 | [241152,249344) | 8 KiB |

三个最终输出均不与mask、P、acc或其他buffer重叠。FP32 store不需要因下一任务覆写这些地址而阻塞其前段VF；仍需保留输出数据生成完成等正常同步。
